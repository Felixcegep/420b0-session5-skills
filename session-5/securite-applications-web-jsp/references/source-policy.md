# Politique des sources — JSP

Source principale : https://jsp.brunocharb.site/

Le site du cours couvre notamment Tomcat/Servlets, JSP, Spring MVC, API REST, JPA, Spring Security et tests.

Priorité :
1. page du cours portant directement sur le sujet;
2. énoncé/code du projet fourni par l'étudiant;
3. documentation officielle Spring/Jakarta;
4. bonnes pratiques générales.

Les versions de Spring/Security évoluent rapidement. Ne remplace pas une configuration du cours par une API plus récente sans expliquer le changement.
