# Checklists

## Controller MVC
- [ ] bonne annotation
- [ ] bonne route/méthode HTTP
- [ ] données reçues correctement
- [ ] logique métier dans service
- [ ] modèle fourni à la JSP
- [ ] redirection/vue correcte

## JPA
- [ ] entités et IDs
- [ ] propriétaire de relation clair
- [ ] `mappedBy` cohérent
- [ ] FK au bon endroit
- [ ] pas de cascade destructive involontaire
- [ ] entité associative si la relation porte des champs

## Sécurité
- [ ] authentification
- [ ] autorisation serveur
- [ ] validation entrée
- [ ] encodage mot de passe
- [ ] secret hors dépôt
- [ ] CSRF/CORS compris
