# Politique de sources — 420-5A4

## Source principale

GitBook du cours :
https://projets420.gitbook.io/420-5a4-conception-de-logiciels

La page d'accueil du GitBook indique deux mécanismes utiles aux agents :

- un index complet dans `https://projets420.gitbook.io/420-5a4-conception-de-logiciels/llms.txt`;
- une version Markdown des pages en ajoutant `.md` à leur URL.

## Ordre de confiance

1. Énoncé/travail/grille d'évaluation fourni par l'utilisateur.
2. GitBook 420-5A4.
3. Notes de cours fournies par l'utilisateur.
4. Standards UML ou génie logiciel reconnus.
5. Bonnes pratiques générales.

Si 1 ou 2 contredit une convention générale, suivre le cours pour une question académique et signaler la différence si elle est importante.

## Recherche recommandée

Quand une question porte sur un terme exact :

1. charger `/llms.txt`;
2. repérer la page correspondante;
3. charger la version `.md` de cette page;
4. chercher le terme exact et son contexte;
5. citer ou paraphraser la règle pertinente sans recopier de longs passages.

Si `/llms.txt` n'est pas accessible :
- utiliser la navigation normale du site;
- rechercher le titre du sujet dans le domaine GitBook;
- demander un lien de page précis seulement si une règle critique reste introuvable et qu'une mauvaise réponse aurait un impact important.

## Langage de confiance

Utiliser ces formulations :

- **« Selon la page du cours… »** seulement après consultation de la page.
- **« En UML, généralement… »** pour une convention externe.
- **« Pour ton travail, je vérifierais ce point dans la consigne… »** si la source exacte n'est pas disponible.
