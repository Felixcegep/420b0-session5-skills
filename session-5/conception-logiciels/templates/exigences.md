# Gabarit — exigences

## Exigence fonctionnelle

`EFxx — Le système doit permettre à [acteur] de [action métier] afin de [objectif, si utile].`

Validation :
- comportement observable;
- une seule fonction principale;
- pas de détail d'UI inutile;
- test possible.

## Exigence non fonctionnelle

`ENFxx — [Composant ou système] doit [critère mesurable] dans [conditions].`

Exemples de critères : temps de réponse, disponibilité, compatibilité, sécurité, accessibilité.
