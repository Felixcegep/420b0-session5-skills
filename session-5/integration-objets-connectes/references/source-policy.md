# Politique des sources — 420-5P0

Source principale : https://cours-5.gitbook.io/420-5p0-integration-dobjets-connectes

Le site indique que la documentation complète est indexée dans `/llms.txt` et que les pages GitBook ont des versions Markdown avec `.md`.

## Priorité
1. Notes du cours 420-5P0.
2. Énoncé/livrable fourni par l'étudiant.
3. Documentation officielle de la bibliothèque ou du matériel concerné.
4. Bonnes pratiques générales IoT.

Ne transforme pas une recommandation générale en « exigence du cours ».

## Versions
Les bibliothèques GPIO, Paho MQTT, Python et distributions Raspberry Pi évoluent. Si une API semble différente du matériel du cours, expliquer la différence de version avant de réécrire le projet.
