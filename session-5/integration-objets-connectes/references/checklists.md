# Checklists

- [ ] capteur initialisé
- [ ] lecture valide

- [ ] payload JSON valide
- [ ] horodatage conforme

## Subscriber
- [ ] connexion au bon broker
- [ ] abonnement avant attente

- [ ] chaque exigence est reliée à une tâche/code
- [ ] aucune périodicité oubliée
- [ ] aucune broche en conflit
- [ ] arrêt sécuritaire des actionneurs
- [ ] topics documentés
