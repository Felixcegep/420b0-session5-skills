# 420b0-session5-skills

AI skills pour la **session 5** du programme **420.B0 — Programmation et sécurité** du Cégep de l'Outaouais, campus Gabrielle-Roy.

## Session 5

- `projet-synthese/` — Projet synthèse
- `conception-logiciels/` — Conception de logiciels
- `integration-objets-connectes/` — Intégration d'objets connectés
- `securite-applications-client-serveur/` — Sécurité des applications client/serveur
- `securite-applications-web-jsp/` — Sécurité d'applications WEB en JSP

## Utilisation des AI skills

Chaque dossier de cours contient un `SKILL.md`. Pour utiliser un skill dans votre agent ou assistant IA, copiez le dossier voulu dans le répertoire de skills configuré (ex. `.skills/<nom-du-skill>/`, etc.) :

```text
skills/<nom-du-skill>/
```

Exemple :

```text
skills/conception-logiciels/SKILL.md
```

Les dossiers `references/` et `templates/` doivent rester avec leur `SKILL.md`.
