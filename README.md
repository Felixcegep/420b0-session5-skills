# 420b0-opencode-skills

Skills OpenCode pour la **session 5** du programme **420.B0 — Programmation et sécurité** du Cégep de l'Outaouais, campus Gabrielle-Roy.

## Session 5

- `projet-synthese/` — Projet synthèse
- `conception-logiciels/` — Conception de logiciels
- `integration-objets-connectes/` — Intégration d'objets connectés
- `securite-applications-client-serveur/` — Sécurité des applications client/serveur
- `securite-applications-web-jsp/` — Sécurité d'applications WEB en JSP

## Utilisation avec OpenCode

Chaque dossier de cours contient un `SKILL.md`. Pour utiliser un skill dans un projet OpenCode, copie le dossier voulu dans :

```text
.opencode/skills/<nom-du-skill>/
```

Exemple :

```text
.opencode/skills/conception-logiciels/SKILL.md
```

Les dossiers `references/` et `templates/` doivent rester avec leur `SKILL.md`.
